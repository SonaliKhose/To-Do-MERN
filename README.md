

# React Todo App

A simple and interactive Todo application built with React, featuring task creation, deletion, completion toggling, and drag-and-drop reordering.

## Features

- **Add Tasks**: Easily add new tasks to your todo list.
- **Delete Tasks**: Remove tasks that are no longer needed.
- **Toggle Completion**: Mark tasks as complete or incomplete with a checkbox.
- **Drag and Drop**: Reorder tasks using a user-friendly drag-and-drop interface.
